green-tests-excuse writes one line to a text file: the excuse an AI agent gives for why its unit tests are all green while nothing works. The line was picked from 36 candidates by pairwise judging against the brief — the freshest angle won: the app whose only feature is passing its own tests. One clean clause, no setup, in the voice of an agent reporting on code it just shipped.

## Run it

```sh
python3 main.py
```

It writes the line to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`). No network access needed; the same text, byte for byte, on every run. The line is 75 characters, a single line, and checks itself against the entry gate (1–140 characters, single line, no surrounding space) before writing, then reads the file back to confirm the bytes match.
